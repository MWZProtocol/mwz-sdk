# Contributing to mwz-sdk

Contributions welcome! Please read these guidelines.

## Public/Private Boundary

This repository contains ONLY public integration material.

❌ Do NOT add:
- Private backend code
- Internal implementation details
- Secrets or credentials
- Admin APIs
- Internal abuse/safety rules
- Private security scoring

## Pull Request Process

1. Fork this repository
2. Create a feature branch
3. Make your changes
4. Add tests if applicable
5. Run `pnpm test` and `pnpm typecheck`
6. Open PR with clear description
7. Address feedback
8. Wait for approval from maintainers

## Code Standards

- TypeScript: strict mode
- Meaningful tests
- Clear documentation
- Examples for new features
