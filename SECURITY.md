# Security

## Reporting Security Issues

Please do NOT open public GitHub issues for security problems.

Email security@mwzprotocol.com with details.

## Public SDK Security

This is a public repository. Assume all content is visible.

## Never Commit

- Private keys or mnemonics
- API credentials or tokens
- Private RPC endpoints
- Secrets of any kind

Use environment variables and GitHub secrets for configuration.

## Public API Stability

Once released, breaking API changes require major version bump.

See [Versioning](./versioning/) for stability guarantees.
